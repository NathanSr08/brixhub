Authentification & En-têtes HTTP

Toutes les requêtes vers l'API v1 nécessitent un Bearer Token valide délivré lors de votre souscription.

En-têtes de Requête

  • Authorization: Bearer <VOTRE_CLE_API>
    Obligatoire. Clé active commençant généralement par brx_live_....
  • Accept: application/json
    Toutes les réponses sont structurées en JSON encodé en UTF-8.

En-têtes de Réponse (Rate Limiting)

  • X-RateLimit-Limit Quota total alloué / 24h
  • X-RateLimit-Remaining Requêtes restantes aujourd'hui
  • X-RateLimit-Reset Timestamp UNIX du reset (00:00 UTC)

Spécifications des Endpoints

Les requêtes de recherche s'effectuent en méthode HTTP GET via Query Parameters.

GET /v1/search
Plans : Standard, Pro, Enterprise

Interroge l'index global par critères combinables ou via recherche textuelle floue. Au moins un critère de filtrage ou une chaîne de recherche globale (q) doit être fourni.

Paramètres d'URL (Query Parameters)

Paramètre Type Exemple Description
q string dupont lyon Recherche globale full-text multi-colonnes.
nom string DUPONT Nom de famille (insensible à la casse et accents).
prenom string Jean Prénom de la personne ciblée.
date_naissance string 1985-04-12 Date complète (format ISO YYYY-MM-DD ou partiel).
jour / mois / annee string jour=12&annee=1985 Filtrage par éléments de date dissociés.
tel string 0612345678 Téléphone (format national ou international +33...).
mail string j.dupont@gmail.com Adresse email (recherche exacte ou par domaine).
code_postal string 75008 Code postal ou préfixe départemental (ex: 75).
ville string Paris Commune de résidence.
source string ALL Nom de la base spécifique (ou laisser vide pour toutes).
limit integer 50 Nombre max d'enregistrements retournés (Défaut: 50, Max: 250).

Exemple de Réponse Réussie (200 OK)

GET /v1/correlations
Plans : Pro & Enterprise

Moteur de pivot automatisé : prend un identifiant clé (téléphone ou email) et extrait automatiquement tous les enregistrements croisés associés à cette même identité à travers l'ensemble des sources.

Paramètres d'URL (Query Parameters)

Paramètre Type Obligatoire Description
tel string Conditionnel Pivot à partir d'un numéro de téléphone.
mail string Conditionnel Pivot à partir d'une adresse email.

Au moins l'un des deux paramètres (tel ou mail) est obligatoire.

Exemple de Réponse Graph/Correlation (200 OK)

{
  "pivot": "0612345678",
  "total_correlations": 3,
  "sources_matched": ["FR_OPERATEUR_2021", "FR_ECOMMERCE_2023", "DELIVERY_PARIS_2024"],
  "identities": [
    {
      "nom": "DUPONT",
      "prenom": "Jean",
      "emails_associes": ["jean.dupont85@gmail.com", "jdupont@entreprise.fr"],
      "adresses_connues": [
        "14 RUE DE LA PAIX, 75002 PARIS",
        "8 BD DES ITALIENS, 75009 PARIS"
      ],
      "derniere_activite": "2024-02-18"
    }
  ]
}

Exemples de code

Intégration rapide dans vos scripts d'investigation ou outils internes.

cURL 
curl -G "https://brixhub.uned.live/v1/search" \
  -H "Authorization: Bearer VOTRE_CLE_API" \
  --data-urlencode "nom=DUPONT" \
  --data-urlencode "ville=PARIS" \
  --data-urlencode "limit=10"
Python (requests) 
import requests

headers = {"Authorization": "Bearer VOTRE_CLE_API"}
params = {
    "nom": "DUPONT",
    "tel": "0612345678"
}

r = requests.get(
    "https://brixhub.uned.live/v1/search",
    headers=headers,
    params=params,
    timeout=10
)

data = r.json()
print(f"Trouvé: {len(data)} enregistrements")
JavaScript (Fetch) 
const params = new URLSearchParams({ nom: 'DUPONT', ville: 'PARIS' });

const res = await fetch(`https://brixhub.uned.live/v1/search?${params}`, {
  headers: {
    'Authorization': 'Bearer VOTRE_CLE_API'
  }
});

if (res.ok) {
  const data = await res.json();
  console.log(data);
}

Codes d'État & Gestion d'Erreurs

Les erreurs API retournent un code HTTP standardisé et un payload d'erreur au format JSON.

Code HTTP Statut Signification & Cause
200 OK Requête traitée avec succès.
400 Bad Request Critère manquant ou syntaxe invalide.
401 Unauthorized En-tête Authorization absent ou format Bearer invalide.
403 Forbidden Clé révoquée, expirée ou niveau de plan insuffisant pour cet endpoint.
429 Too Many Requests Quota quotidien de requêtes dépassé ou rate-limit par seconde atteint.
500 Internal Error Erreur interne du moteur de stockage ou de base de données.

Format Payload Erreur (4xx / 5xx)

{
  "error": true,
  "status_code": 429,
  "code": "DAILY_QUOTA_EXCEEDED",
  "detail": "Votre quota quotidien de 1 000 requêtes est épuisé.",
  "reset_timestamp": 1774828800
}
